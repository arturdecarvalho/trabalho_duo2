# 🌂 Guarda-Chuva

Conversão do algoritmo "GuardaChuva" (Portugol) para JavaScript.
Projeto da atividade **Conversão da Linguagem**, feito em dupla.

## O que faz
Pergunta a chance de chuva (%) e informa se é preciso levar guarda-chuva
(chance acima de 50%).

```bash
git clone <https://github.com/arturdecarvalho/trabalho_duo2.git>
cd guarda-chuva
node guarda-chuva.js
```

## Exemplo
```
Digite a chance de chuva (em %): 70
Leve o guarda-chuva!
Consultar novamente? (s/n): n
```

Veja `original/guarda-chuva.alg`.
